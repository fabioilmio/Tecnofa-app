# TECNOFA

Gestionale personale per attività tecniche, clienti, impianti, interventi, agenda, economia, energia e percorsi.

## V1 attuale
- Dashboard operativa
- Agenda
- Clienti con coordinate GPS
- Schede impianto
- Interventi
- Mappa con OpenStreetMap / Leaflet
- Creazione percorso stradale tra più clienti tramite OSRM
- Geolocalizzazione del dispositivo, quando autorizzata
- Backup JSON locale
- Struttura PWA responsive desktop/mobile

## Moduli previsti
Dashboard · Agenda · Clienti · Impianti · Interventi · Manutenzioni · Preventivi · Magazzino · Economia · Documenti · Mappa & percorsi · Energia · TECNOFA AI · Impostazioni.
